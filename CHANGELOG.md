# FotoAsist GC — changes

## 1.0.0

First open-source release (GPL-3.0-or-later).

- Free: no account, activation, trial or licensing server. Every feature of this edition is always available.
- The source of the application is public and open to contributions.
- Display output uses the open display transform to sRGB.
- Not part of this edition: GDC DRT, selective colour and skin, diffusion and bloom, photochemical film, look and cinema style libraries, the Resolve OFX plug-in. Their panels are hidden; saved values are kept and have no effect.
- "Check for updates" reads the latest release of the public repository. Nothing is installed automatically.
- Includes the RAW development changes of 0.9.2: Fujifilm GFX black level and full 4:3 frame, RAW development panel, existing edits are never changed automatically.

Earlier versions (0.5.0 – 0.9.2) were distributed as installers only: https://gordas.dev/foto-asist-gc/
