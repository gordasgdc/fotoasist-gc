## Contributors

Contributors are the people whose commits are in this repository's history (`git shortlog -sn`). When your first pull request is merged, add your name here in the same pull request if you want to be listed.

Authorship in this project names people. Commit authors and `Co-authored-by` trailers identify the persons responsible for a change; tools used while writing it are not authors and are not listed.

Third-party code and data keep their own copyright notices: see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
